# 脱敏公开版：运行与复现说明

本版保留可执行的搜索规则、A* 预计算、策略接口、实验运行和路径还原。演化实现、论文关键参数、真实数据、训练完成的 D/Q、实验数值和历史记录均不随公开包发布。

这里的“可复现”指：持有原始私有输入时，用公开的搜索程序复现冻结策略的路径求解实验。公开包还提供独立合成示例，可直接运行。仅凭公开文件无法精确复现被移除的论文数值，也不能重新训练得到被移除的策略。

## 安装并运行合成示例

建议使用独立 Python 环境，避免与完整私有工程混用：

```sh
python -m pip install -e .
python -m unittest discover -s tests -v
python -m llm_alns_b demo --output runs/demo
```

示例会自动生成小型合成地图与任务点，执行 A* 预计算、实际搜索和路径展开。示例参数专门用于演示，不代表论文设置；演示策略是简单的功能示例，不是论文训练策略。整个过程不联网。

## 使用私有材料复现搜索

将以下材料保留在仓库以外的本地目录：

- 原始地图、任务点、距离矩阵与预计算路径。
- 原始冻结 D/Q 源码及其文件校验清单。
- 完整搜索参数配置、实例名称与求解种子。
- 引用上述文件的 `experiment.json`。

```sh
python -m llm_alns_b validate --experiment 私有目录/experiment.json
python -m llm_alns_b run --experiment 私有目录/experiment.json --output 本地结果目录
```

精确复现还需要兼容的数值环境，保持节点顺序、实例名、策略代码及参数一致。实例名参与随机数派生，因此不能随意重命名实例。

结果包含有效参数快照、输入身份、每轮搜索轨迹、服务顺序、目标值和完整网格路径。服务任务恰好访问一次；网格航迹允许重复经过水域单元。目标值是归一化网格移动距离，不能直接作为实测运行秒数。

## 保留的搜索实现

保留初始化、算子选择、Q 决定移除规模、D 移除任务、修复、最优解更新、模拟退火接受及权重更新。随机数按角色隔离。原语与修复规则继续执行，关键控制数值由外部配置显式提供，缺项报错，不自动填入论文数值。

本公开版没有模型 API、提示词、演化控制器和训练入口。程序解释器的安全上限、基本几何常量和标准数学定义属于运行必需的通用实现。

## 上传范围

只上传新的脱敏目录或对应压缩包。原完整工程、此前生成的完整压缩包、私有复现材料及新产生的真实实验结果都应留在本地。`.gitignore` 已忽略常见私有目录与运行输出；它不能阻止网页手动上传被选中的文件。
